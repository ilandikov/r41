| ----------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Магистральный провайдер | На локации нет upliknk-подключения                                         | На локации есть uplink-муфта, подключенная к магистральному провайдеру | Тех. директор делает запрос к магистральному провайдеру на подключение. Провайдер может отказаться по своим причинам (неизвестны), в этом случае, если это экономически выгодно, тех. директор может решить протянуть uplink из другой локации. |
| Инженер-строитель       | На локации нет upliknk-подключения                                         | На локации есть uplink-муфта, подключенная к другой локации            |                                                                                                                                                                                                                                                 |
| Инженер-строитель       | На локации есть uplink-муфта                                               | На локации проведена сеть                                              | ИС строит объекты по одному, поэтому ему нужен вид разварки на одну муфту.                                                                                                                                                                      |
| Сервис-инженер          | На локации произошла авария - у некоторых абонентов нет доступа в интернет | Авария устранена                                                       | Устранение аварии по схеме из linkup, либо нужно известить отдел тех. условий об изменении сети.                                                                                                                                                |
| Сервис-инженер          | На локации появился новый абонент, которого нужно подключить               | Абонент подключен                                                      | Подключение по схеме из linkup, либо нужно известить отдел тех. условий об изменении сети.                                                                                                                                                      |
